# Frontend — SalesPulse Analytics UI Layer

This folder contains all Streamlit dashboard and data visualisation files for the SalesPulse project.

## Files

| File | Assignment | Description |
|---|---|---|
| `app.py` | 2.51 | Main multi-section Streamlit analytics dashboard with sidebar navigation |
| `streamlit_export_integration.py` | 2.50 | Streamlit export hub with one-click CSV, PDF, and HTML download buttons |
| `kpi_dashboard.py` | 2.47 | KPI card summary dashboard with directional trend indicators |
| `dashboard_app.py` | Earlier | Interactive dashboard prototype |
| `assignment-35-visualizations.py` | 2.45 | Business visualisation principles — chart type selection demo |
| `dashboard_design.md` | 2.45 | Dashboard design specification and chart palette conventions |

## Running the Main App

```bash
# From the project root:
streamlit run frontend/app.py
```

## Dependencies

All dependencies are listed in `requirements.txt` at the project root.
